Procesamiento de texto

Eliminar muletillas

Remueve "este", "eh", "o sea", "um", "uh" automaticamente.

Dictado de puntuacion

Di "coma", "punto", "nueva linea" para insertar signos.

Puntuacion por pausas

Silencio largo → punto, silencio corto → coma. Requiere desactivar dictado de puntuacion.

Modo Low-volume

Mayor sensibilidad del microfono para espacios silenciosos o reuniones.

Formalidad con IA (Claude Haiku)

Reescribe el texto en el tono del contexto activo. Agrega ~400ms de latencia.

🚀 Modo Calidad (Claude Haiku)

Post-procesa con IA para transcripciones casi perfectas. Corrige errores, mejora puntuacion. +700ms.
